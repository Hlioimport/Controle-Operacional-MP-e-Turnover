FONTE DE WRAPPER ANDROID

Este diretório contém o HTML dentro de um WebView. Para gerar um APK, crie um projeto Android Studio vazio com módulo app, copie app/src/main para o módulo e compile em Build > Generate App Bundles or APKs > Generate APKs.

O APK não foi compilado neste ambiente; o index.html/PWA é a versão pronta para uso imediato.
